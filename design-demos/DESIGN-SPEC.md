# SCUT Racing Telemetry — F1 官方风格设计规范

> **唯一设计基准**：`design-demos/08-f1-data-analysis.html`（零外部依赖，字体已 base64 内嵌，双击即开）  
> **风格来源**：formula1.com Live Timing 官方视觉语言（真实 token 抠自官网 470KB CSS）  
> **定稿日期**：2026-09-15（用户逐条拍板）

---

## 1. 设计原则

1. **F1 官方风格**：深黑底、硬朗几何、斜切点缀、宽扁大写标题。
2. **克制（用户明确要求）**：全页黑白灰为主，红色是唯一主色且只出现在有明确功能含义的位置；无大面积彩色，无渐变，无阴影堆砌。
3. **标题及重点区域才用 Display 字体**：字符少且重要的地方（比赛名、文件名、大数字）用 Formula1-Display-Bold，其余一切用 Titillium。满屏 Display = 花哨，官方从不这么干。
4. **通道用固定色板区分**：色条 → 曲线 → 图例 → 详情色条，四处同色一一对应。

| 通道       | 色值        | 备注                 |
| -------- | --------- | ------------------ |
| SPEED    | `#FFFFFF` | 白（最常用通道，白最稳）       |
| RPM      | `#B14BF4` | 紫                  |
| THROTTLE | `#43B02A` | 绿                  |
| BRAKE    | `#E10600` | 红                  |
| STEERING | `#28F3D2` | 青（官方 Mercedes 车队色） |
| GEAR     | `#FFD100` | 黄（官方 medium 胎色）    |
| LAT G    | `#FF8001` | 橙（官方 McLaren 车队色）  |

**色板四处联动**：左侧列表 3px 色条 / 曲线颜色 / 图例色条+当前值颜色 / 右下详情标题前色条，全部取同一色值。  
新增通道时从未用色相中取色，避免与现有通道冲突。

### 2.4 红色使用边界（克制原则的硬规则）

红色 `#E10600` **只允许**出现在：

1. logo 底色
2. 顶栏底部 2px 分隔线
3. 主按钮（ADD COMPARE）底色
4. 通道选中态的 3px 左边条
5. 时间轴窗口框（含两端手柄）
6. 赛道图上的车辆箭头 + 起终点线
7. 文件名中高亮的片段（如 `MADRING_FP2_R2` 中的 `FP2`）
8. MAX 数值（语义双关）

**其余一切**：白色曲线、灰色网格、白色/灰色文字。hover 边框变红允许（ghost 按钮的 hover 反馈）。

## 4. 布局结构

### 4.1 整体框架

```
┌──────────────────────────────────────────────────────┐
│ 顶栏 54px（--bg2 底 + 底部 2px --red 分隔线）           │
├──────────┬────────────────────────────┬──────────────┤
│          │                            │              │
│  左栏     │        中栏（弹性）          │   右栏        │
│  280px   │  ┌──────────────────────┐  │   310px      │
│          │  │ 图表堆叠区（flex:1）    │  │              │
│ 文件卡片   │  │ 每通道一个图表均分高度   │  │ 赛道图 300px │
│ +        │  │                      │  │              │
│ 通道列表   │  ├──────────────────────┤  │ +           │
│ (滚动)    │  │ 时间轴 110px          │  │ 通道详情(滚动)│
│          │  └──────────────────────┘  │              │
└──────────┴────────────────────────────┴──────────────┘
```

- `body`：`overflow:hidden`、`user-select:none`、底色 `--bg`、默认字体 Titillium 13px。
- 主区 CSS Grid：`grid-template-columns: 280px 1fr 310px`；三栏均 `min-height:0`（防溢出）。
- 左栏右边框 1px `--line`；右栏左边框 1px `--line`；中栏底部时间轴顶部 2px `--red` 分隔。

### 4.2 顶栏（54px）

- 左→右：logo → 比赛名 + 副标题（baseline 对齐，间距 10px）→ flex spacer → PLAY → EXPORT → ADD COMPARE。
- **logo**：红底白字，`padding: 6px 14px`，外层 `skewX(-10deg)` 斜切、内层 `skewX(10deg)` 反斜切（文字正、块斜）。
- **ghost 按钮**：透明底、1px `--line` 边框、`padding: 7px 16px`；hover 边框变 `--red`（文字不变色）。
- **主按钮**：`--red` 底 + 同色边框 + 斜切（同 logo 手法）。
- 播放中：PLAY 变为 PAUSE 且变主按钮样式（红底）。

### 4.3 左栏（280px）

**文件卡片**（上，`padding: 0 14px 12px`，底部 1px 分隔线）：

1. 分区标题 `DATA FILE`（左侧 3×12px 红色小块 + F1 Display Bold）
2. 文件名（F1 Display Bold 15px，可换行 `word-break:break-all`，关键词红色）
3. chips 一行：`RATE 500Hz` `LAPS 14` `SIZE 82.4MB`——`--panel` 底 + 1px `--line` 边框，标签 `--dim` / 数值白
4. 元数据表（两列，左灰右白右对齐）：车手 / 赛车 / 时长 / 通道数 / 最快圈（紫）
5. 通道计数徽章：分区标题右侧 `86 CH`

**通道列表**（下，占满剩余高度，滚动条 6px `--line`）：

- 每行结构：`[勾选框 14×14] [3px 色条] [通道名] ··· [单位]`，`padding: 8px 14px`，`gap: 10px`
- 勾选框：1.5px `--dim2` 边框空心；选中 = 白边框 + 内部 inset 2px 白色实心块
- 选中态：`--bg2` 背景 + 3px `--red` 左边条；hover = `--bg2` 背景
- 点击行 = 切换勾选 → 联动中栏图表增删 + 右下详情增删

### 4.4 中栏（弹性）

**图表堆叠区**：

- 容器 flex column，`overflow:hidden`；每个通道一个 `.chart`，`flex:1` 均分高度（`min-height:60px`），图表间 1px `--line` 分隔
- 无勾选通道时显示居中提示「从左侧勾选通道以显示图表 / SELECT CHANNELS」（`--dim2`）
- 每个图表 = canvas（absolute 铺满）+ 左上角图例 DOM
- **图例**（小号集中左上角，`top:5px; left:10px`）：`▍ SPEED 247 km/h` = 3×11px 色条 + 通道名（10px `--dim`）+ 当前值（11px 通道色）+ 单位（9px `--dim2`）；`pointer-events:none`
- 图表区 `cursor: ew-resize`

**时间轴**（110px，`--bg2` 底）：

- 全程速度缩略曲线：`rgba(155,155,173,.4)` 1px（全程数据下采样）
- 窗口外遮罩：`rgba(21,21,30,.72)`
- 窗口框：`--red` 2px 描边 + 两端 4px 宽红色手柄
- 窗口起止时间：白字 11px，分别在框内左右下角
- 数据游标位置：白色 1.5px 竖线（全程可见）
- 右上提示小字 `DRAG = PAN · WHEEL = ZOOM`（`--dim2`）

### 4.5 右栏（310px）

**赛道图**（300px 高，border-bottom 分隔）：

- 画布留白：`scale = min(w,h) × 0.82 × zoom`，居中偏上
- 赛道线：白色 7px 外描 + `--bg` 色 4px 内描（空心管效果），`lineJoin/lineCap: round`
- 起终点线：红色 3×16px 短竖线
- 弯道编号：T1/T3/T9/T13 灰字（数据来自赛道定义）
- 车辆尾迹：白色 35% 透明 2.5px，跟随游标前 ~11 秒
- 车辆：红色箭头形（前 9px 后 6px 舵形），白色 1px 描边，按切线角旋转
- **HUD**（左上，`pointer-events:none`）：两组「标签 10px `--dim` + 数值 22px 白」——T · CROSSTIME（`m:ss.mmm`）和 SPEED（km/h）
- **缩放按钮**（右上纵排）：26×26px，`--panel` 底 1px `--line` 边框，`＋ － ⟲`；hover 边框和字符变红；缩放范围 0.6×–3×，步进 1.25×，⟲ 复位

**通道详情**（占满剩余高度，滚动）：

- 每通道一张卡片（`padding: 10px 14px`，卡片间 50% 透明分隔线）：
  1. 标题行：3×12px 通道色条 + 通道名（12px 700）+ 右侧单位
  2. 当前值：**F1 Display Bold 24px 白** + 小号单位
  3. 三格 grid（`gap:6px`）：MIN（绿）/ MAX（红）/ AVG（白）——格子 `--bg2` 底，标签 9px `--dim2` 上下结构
- 当前值跟游标实时更新；MIN/MAX/AVG 为**全程**统计（非窗口内）

## 5. 图表绘制规格（canvas / 迁移 uPlot 时对照）

| 项           | 值                                                                |
| ----------- | ---------------------------------------------------------------- |
| 绘图区 padding | 左 34（y 刻度）/ 右 8 / 上 26（图例空间）/ 下 14（x 刻度）                         |
| 水平网格线       | 4 条（含顶底），`rgba(56,56,74,.55)` 1px                                |
| y 刻度        | 3 等分（min+range×k/3），右对齐，Titillium 600 10px `--dim2`，按通道 dec 保留小数 |
| x 刻度        | 自适应步长：跨度 >40s→10s / >15s→5s / >6s→2s / 否则 1s，格式 `12s`            |
| y 轴范围       | 窗口内 min/max ±12% 余量；GEAR/BRAKE/THROTTLE 从 0 起、顶部加 10% 余量         |
| 曲线          | 通道色 1.5px；数据点下采样至 ≤2×宽度像素                                        |
| 游标线         | `rgba(255,255,255,.55)` 虚线 `[4,4]`，全高                            |
| 游标交点        | 半径 3.5px 通道色实心圆（仅游标在窗口内时绘制）                                      |
| DPR         | `devicePixelRatio` 适配，`setTransform` 缩放                          |

## 6. 交互规范（核心约定，用户逐条拍板）

### 6.1 数据游标（cursor）

- **默认位置 t=0**，**不随鼠标悬停移动**（禁止 hover 跟随）。
- 移动方式：**在图表区按住鼠标拖动**；按下即跳到该点，拖动实时跟随，松手停在原地。
- 游标是全局唯一状态，驱动：每个图表的虚线+交点+图例数值、右下详情当前值、赛道车辆位置+尾迹+HUD、时间轴白线。
- 游标超出当前窗口时：图表不画线，但详情/赛道仍显示该时刻数据（clamp 到全程范围）。

### 6.2 图表区手势

| 手势      | 行为                                                              |
| ------- | --------------------------------------------------------------- |
| 滚轮（上/下） | 缩放时间窗：以**鼠标横向位置为焦点**，每档 ×1.18 / ÷1.18，窗口最小 2s、最大全程；缩放后焦点保持在原时间点 |
| 按住拖动    | 移动数据游标（见 6.1）                                                   |

### 6.3 底部时间轴手势

| 手势   | 行为                                                 |
| ---- | -------------------------------------------------- |
| 按住拖动 | 平移时间窗，**窗口跟手**：鼠标向右拖 → 窗口向右移动（内容跟手，类似拖地图）；触边 clamp |
| 滚轮   | 缩放时间窗，焦点=鼠标位置（与图表区行为一致）                            |

### 6.4 播放

- ▶ PLAY：游标以 0.05s/帧（≈20fps）从窗口起点扫到窗口终点，循环；出窗重置到窗口起点。
- 播放中按钮变 `❚❚ PAUSE` 且红色主按钮样式。

### 6.5 其他

- 通道行点击：勾选/取消，图表与详情即时增删（无动画要求）。
- 赛道缩放按钮：见 4.5。


## 9. 正式软件落地决策（2026-09-15，负责人拍板）

以下决策将本规范从"单 demo 深色稿"扩展为正式软件的完整设计契约，与正文冲突时以本节为准：

### 9.1 浅色主题保留（红 + 白）

深色（正文 token 表）为默认主题；浅色主题采用**红 + 白**配色，token 推导规则 = 黑白互换、红与彩色语义保持：

| Token     | 浅色值      | 说明                                  |
| --------- | --------- | ----------------------------------- |
| `--bg`    | `#FFFFFF` | 页面主底                                |
| `--bg2`   | `#F2F2F6` | 次级面板（顶栏/时间轴/选中行/MIN-MAX-AVG 格）       |
| `--panel` | `#E9E9F0` | 三级面板（缩放按钮/chip 底）                    |

### 9.2 布局扩展：三栏宽度可调 + 状态栏保留

- 左右两栏宽度**可拖拽调整**：左栏 220–420px（默认 280）、右栏 240–480px（默认 310）；分割条视觉 1px `--line`、命中区 6px、拖拽与 hover 时变 `--red`；
- 栏宽状态入 zustand（`leftWidth` / `rightWidth`），后续经 `save_layout` 持久化；
- **底部状态栏保留**（24px）：`--bg2` 底、顶部 1px `--line`、11px `--dim`、tabular-nums、项间竖分隔；内容 = 游标时间 | 视口 | 通道 勾选/总数 | 缓存状态 | 代际。

### 9.3 结构决策

- **dockview 移除**：固定三栏 Grid 取代自由停靠；面板组件（registry 架构）保留、仅换容器；`save_layout`/`load_layout` 后端命令保留，前端"预设"退化为左右栏显示/隐藏；
- **圈速面板不做**：圈数据只出现在文件卡片（LAPS chip、紫色最快圈数值）；
- **导入入口**：资料库主页（后续 Step）落地前，无数据集时顶栏中部显示 ghost 样式路径输入框 + 导入按钮；有数据集后该位置显示文件名（F1 Display Bold）+ 副标题；
- 顶栏右侧按钮序列：▶ PLAY / ❚❚ PAUSE（播放功能按 6.4）、EXPORT（调 `exportCsv`）、ADD COMPARE（Step 15 前禁用置灰）、主题切换 ◐ ghost 钮、状态灯。
