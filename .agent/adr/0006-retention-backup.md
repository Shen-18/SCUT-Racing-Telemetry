# ADR 0006 — D10 保留与备份

状态：已采纳（2026-09-11）；实现按施工步骤推进。

## 决策
原始 XRK/CSV 永久只读，软件不得清理或覆盖。pyr 永驻；raw 默认保留，XRK 优先；缓存默认不设硬上限，可选上限默认关闭。提供按单数据集/全部清理衍生缓存入口，不删除原始数据与用户数据库。

## 理由
pyr 支撑快速开图，raw 避免 XRK 再解析。缓存是可重建衍生物，备份只包括原始文件及包含注释/布局/索引的 telemetry.db 在线一致性快照，不上传 raw/pyr。

## 影响与边界
清理与空间不足不得伪标 Ready；重开检查 manifest/源身份/版本/checksum。实现归 Step 9A/13；根目录 Data 是只读样本，不是应用运行缓存。
