# ADR 0002 — IPC 控制面与 Job API

状态：已采纳（2026-09-11）；实现按施工步骤推进。

## 决策
控制面使用 JSON 小对象；曲线窗口采用 Step 4 二进制帧，严禁完整数据集跨 IPC。唯一前端入口 src/api/client.ts，类型于 Step 4 由 specta 生成。startImport(path) -> JobId，startImportBatch(paths, recursive) -> JobId[]；importStatus(jobId)、cancelImport(jobId)、prioritizeImport(jobId, channels) 使用手册 Step 4/5 签名。ImportStage 由 cache-core 定义，IPC 不拥有缓存状态。

## 理由
慢导入需后台 Job，元数据先可见；窗口按像素查询避免 JSON 大数组。windowSeries 请求与帧回显 generation，客户端丢弃过期响应；取消与优先级调整不阻塞 UI。

## 影响与边界
ReadingMetadata → ReadingChannels → BuildingRawCache → BuildingPyramid → Ready | Failed | Cancelled；状态轮询是权威读取，事件仅作通知，失败须携带错误信息。具体序列化错误结构、帧字节布局以手册 Step 4 为准，不在本 ADR 新造协议。Step 1 仅记录决策，不提供假成功 IPC。
