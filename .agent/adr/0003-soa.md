# ADR 0003 — SoA 与独立时间轴

状态：已采纳（2026-09-11）；实现按施工步骤推进。

## 决策
ChannelSeries 使用独立的 f64 times 与 f32 values 数组，并保持一一对应；数值外的文本不强塞 f32。ChannelMeta 含 dtype，SessionMeta 保存文件主频，单通道频率属于 ChannelSeries。DatasetId 采用 Rust 契约，不复制 Python UUID/DataFrame。

## 理由
不同通道频率与时间戳不一致，统一重采样会制造误差与多余扫描。SoA 支持 mmap 布局与二进制窗口读取，CSV 是物理真值，legacy Python 仅兼容参考。

## 影响与边界
核心只进行纯计算；GPS 依据 gps_raw ECEF 派生；export 仅写 std::io::Write，文件创建归边界层。算法、非有限值与重复名规则在 Step 2/6/7 用真值测试冻结。
