# 当前架构

更新：2026-10-17，依据本地代码（版本 1.3.0）。完整历史约束见 [归档](archive/2026-10-09/README.md)。

## 技术栈与模块

桌面端：Tauri 2、Rust、React 18、TypeScript、Vite 6、uPlot、Zustand、WebView2。生产前端与 Rust 后端编入程序，用户无需 Node、Rust 或独立 HTTP 后端。云端单独部署 Node.js HTTP + PostgreSQL 16，管理员网页为原生 HTML/CSS/JS。

| 模块 | 职责 |
| --- | --- |
| telemetry-core | 数据模型、统计、时间轴和 GPS 纯算法 |
| aim-ffi / csv-parser | AiM DLL 边界与 CSV 解析 |
| cache-core | manifest、原文件归档、raw、校验与目录迁移 |
| telemetry-store | 本地 SQLite 连接、迁移、索引、备注与分析偏好 |
| telemetry-ipc | DTO、二进制窗口帧与错误结构 |
| overlay | 时间线、绑定、HUD 与透明帧渲染 |
| src-tauri | 导入任务、读图、导出、下载和系统功能协调；overlay_export 协调 FFmpeg 编码与 ffprobe 校验 |
| xrk-meta | 服务器独立 XRK/XRZ 元数据解析（编译为 Linux musl 二进制，不进入桌面安装包） |
| server | 认证、文件分发、日期备注、软件发布与更新 |

Rust workspace：8 个业务 crate、Tauri 壳、golden-tests，共 10 个成员。直接依赖边界见 config/contracts/dependencies.json，依赖变更同步 manifest、锁文件与契约。前端数据命令集中 src/api/client.ts；自动更新封装在 src/api/updater.ts。纯业务模块避免依赖桌面层。

## 本地 SQLite 与数据

数据根取自 `std::env::current_exe()` 的父目录，即实际运行的 EXE 同目录下 `data/`；开发态找不到 EXE 目录时回退到工作区 `.cache/`。`SCUT_CACHE_ROOT` 优先级最高，同时覆盖数据库与缓存位置。目录需要可写。SQLite bundled 编入程序，无需额外数据库服务。

~~~text
data/
  telemetry.db
  datasets/
    <日期>_<车手>_<车辆>_<场次>_<哈希前12位>/
      manifest.json
      source.<原始扩展名>
      channels/<校验和>.raw
  cloud-downloads/<哈希>.<扩展名>  # 下载中转
~~~

命名组件经过安全字符处理，缺失字段使用 UNKNOWN_DATE/DRIVER/CAR/SESSION。完整 SHA-256 用于内容去重和云端比对；UUID record_id 是本地稳定身份，临时打开句柄不是主键。SQLite 存相对数据集路径，迁移时带走整个 data 目录。

| SQLite 表 | 实际用途 |
| --- | --- |
| schema_meta | 结构版本，当前版本 2 |
| datasets | 稳定身份、元信息、相对目录和缓存状态 |
| dataset_channels | 通道清单及顺序 |
| dataset_preferences | 每条记录的 selected_channels_json |
| record_notes | 本地单条备注，不联网回传 |
| local_record_notes | 旧备注表，迁移复制到 record_notes 后保留兼容 |
| date_notes | 本地日期备注及旧值 |

manifest.json 是缓存元数据与恢复依据；列表总索引、用户单条备注和偏好由 SQLite 管理。JSON 仍用于 manifest 及 SQL 内部分序列化字段。列表查询读 SQL，启动对账接入已有 manifest，导入完成更新索引；恢复扫描不应覆盖备注与偏好。原文件与 raw 是磁盘文件，不把大数组塞进总索引。恢复记录索引不能恢复仅存 SQL 的用户数据。

## 备注与设置

单条记录支持右键“编辑备注”或点击备注列编辑，存本地 SQL，不回传云端；操作列仍只有下载与删除。编辑对话框由保存/取消/Esc 关闭，点击外部或拖动选择文本不关闭。日期备注由云端管理员维护。库页按日期合并：云端存在时优先，否则保留本地值。当前合并只用于页面展示，未持久化云端备注供离线使用。

“记住上次选择的通道”默认关闭。开启后按记录保存/恢复顺序，过滤不存在的通道；明确选空与从未保存偏好不同。开关存 localStorage，记录偏好存 SQLite。

设置按钮在主题切换旁，顶部栏颜色跟随所在页面；Database 与 Overlay 的设置需求区分。Database 当前提供服务器地址、密钥、连接检查、启动自动同步与手动同步。GPS / Detail 分割比例是布局功能，不由通道记忆开关控制。

设置页同一按钮变为 BACK，返回原 Database/Overlay 页面。顶部 DATABASE/OVERLAY 文字每次进入悬停播放一次红/蓝扫光，持续悬停不循环。记录“打开文件目录”优先定位归档 source 文件，兼容旧原路径和无源文件的缓存目录，不再依赖已清理的 cloud-downloads 中转路径。

前端 localStorage 键（源码实际使用）：

| 键 | 用途 |
| --- | --- |
| scut.remote-server-url | 云端 Base URL，同步与更新共用 |
| scut.remote-token | 客户端访问密钥 |
| scut.remote-autosync | 启动自动同步，默认开 |
| scut.remember-selected-channels | 通道记忆开关，默认关 |
| scut.track-map-splitter | GPS / Detail 分割比例 |
| scut.overlay.select-layout / scut.overlay.workbench-layout | Overlay 选择页与操作台栏宽 |
| scut.overlay.bindings.<fileHash> | 每条记录的通道绑定 |

## 分析与 Overlay

图表主路径直接读 raw；每通道独立 f64 时间轴与 f32 数值，按窗口传二进制帧，generation 丢弃过期响应。新记录不依赖 pyr；启动迁移清理已有 raw 的旧 pyr。相关模块仍在代码中，不能只看文件名判定源码闲置。

缺失值、真实时间间隔、游标与插值保持一致，避免跨缺口补点；统计跳过非有限值。Y 轴只显示数值，单位在图例；中键横向拖动平移时间窗口；GPS / Detail 可拖动分割，GPS 使用等比例几何。入口为 PlotStack、uPlotFactory、TrackMapPanel、trackMapGeometry。本轮未重新做 GUI 验收。

Overlay 从 raw 取数据，Rust 绘制透明帧，FFmpeg 编码 MOV，ffprobe 校验。同步语义 video_seconds = data_seconds * scale + offset_seconds；支持锚点、padding、可配置尺寸/输出帧率/渲染帧率、QTRLE 与 ProRes 4444、进度与取消。编码按分块并发后 concat，FFmpeg 日志写入输出文件同名的 `.log`；校验通过后才替换最终文件。完整边界见 [Overlay 原规格](archive/2026-10-09/docs/superpowers/specs/2026-10-03-overlay-video-export-parity.md)。

Overlay 选择页与操作台三栏可分别拖动并保存布局（localStorage scut.overlay.select-layout / workbench-layout），右栏默认 220px；选择页用小方框与蓝色高亮代替 SELECT/SELECTED。

### FFmpeg 资源与查找

`resources/ffmpeg.exe` 与 `resources/ffprobe.exe` 通过 tauri.conf.json 的 bundle.resources 映射到安装目录 `resources/`；`resources/` 已加入 .gitignore，不入库。运行时查找顺序：`IMAGEIO_FFMPEG_EXE` → EXE 同目录 `ffmpeg.exe` → EXE 同目录 `resources/ffmpeg.exe` → 当前工作目录 `resources/` 与 `target/release/`（开发回退）→ PATH。ffprobe 优先 FFmpeg 同目录，否则用 PATH。AiM DLL 则先找 `resource_dir()`，再退到 `TestMatLabXRK/DLL-2022`。

## 云端边界

PostgreSQL 存索引、日期备注、管理员、会话、客户端令牌与发布记录；原文件和安装器位于 uploads，SQL 存关联键。客户端不上传本地 SQL，也不拉取整库覆盖。

管理员上传，客户端拉缺少的记录；本地单条备注、通道偏好和本地删除不回传。云端删除不自动删除客户端已有记录。同哈希元信息变更同步尚未实现。详见 [发布与同步](发布与同步.md)。
